# Rugged Glory USA — Custom Axe Designer

Interactive ceremonial axe configurator for [ruggedgloryaxes.com](https://ruggedgloryaxes.com).

Firefighter / police / military memorial axes — customize handle color, blade seal,
engraving, memorabilia, and dedication plaquard in real time.

## Run locally

Open `index.html` in any modern browser. Static single-file app — no build step.

## Deploy

Netlify: drag-and-drop the repo folder at [app.netlify.com/drop](https://app.netlify.com/drop), or connect this GitHub repo for continuous deploys.

## Stack

- Single-file HTML + Tailwind CDN
- Base-image customizer (Axe-only.png → axe-base-tight.png) with CSS filter recoloring
- Inline SVG seals, memorabilia library, drag-drop overlays
